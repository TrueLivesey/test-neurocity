# Тестовое задание для компании Neurocity

- В качестве сборщика использовался Vite
- Препроцессоры: SASS, POSTCSS
- HTML-файлы разбиты на части и находятся в src/assets/partials
- JS-файлы распределены на модули и находятся в src/assets/js
- **Задание 4 разделено на 3 файла**. Каждое запускается командами
  - **node src/assets/js/task4_1.js**
  - **node src/assets/js/task4_2.js**
  - **node src/assets/js/task4_3.js**

## Установка и запуск

- Установить зависимости **npm i**
- Запустить проект **npm run dev**

## Особенности

### Задание 1. Слайдер

Слайдер настраивается в main.js при создании экземпляра класса Slider. Сначала в него передается элемент слайдера, затем в качестве объекта настройки. Настроек несколько:

- cardsPerView --- количество слайдов (карточек) на экране
- isInfinite --- бесконечная прокрутка (условная)
- padding --- на самом деле gap

### Задание 3. Загрузчик файлов

Решил добвить два мода: для загрузки всех файлов и для загрузки только тех файлов, у которых размер больше нуля, так как есть три файла с size: 0. Первый мод называется _all_, а второй _sizeOnly_. По дефолту второй стоит
